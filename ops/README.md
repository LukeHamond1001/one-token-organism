# ops — the served body's operations

What runs the served body day and night, and nothing that reads from inside it on the caregiver's behalf.

Live files:
- `BASE_FLAGS.txt` — the served constants as flags, one line; the source of truth beside the save (`served_cfg.py` prints a save's effective constants against it). `serve_command.txt` (the exact serve command last used) carries the same flags and must stay identical to it. `typist_chain_command.txt` — the typist chain's quoted command.
- `RESTART.md` — the restart procedure after a reboot, and the rule for every reload (explicit values for every changed constant; then `served_cfg.py`).
- `reload_after_save.sh` — a reload of the served body at the next post-night save with given flags (the boundary at which constants change). `rekey_after_save.sh` — the same boundary with the store rebuilt from the utterance memory first (a change of the key's form needs it; night 262). `probe_after_save5.sh` — the morning probe after each night's save (the language probe, every prefix and question listed, the rephrased set; keeps the morning save two deep). `probe_at_dusk.sh` — the dusk save and its probe; no longer armed, by hand only (RESTART.md). `stop_all.sh` — stop everything cleanly for a reboot.
- `night_cycle.sh` — the standing loop for the days and nights (2026-09-20, replacing the night waiter): keeps the queue fed, prints the day's count at each night (`day_report.py`), runs the morning probe at each save, and queues the morning rows, the day's script, story rows (`read_stories.py`) and revisits (`revisit_rows.py`).
- `queue_depth.py` — the lines ahead of the typist (the only depth a parent may read). `day.py` — a day's tally from the page log (its only caller was the retired night waiter; `day_report.py` is the cycle's count). `served_cfg.py` — a save's constants against the flags. `talk_proxy.py` — the visitor's page served beside the body (the same page the body serves at `/talk`).
- `parent_brief_human.txt` — the human teacher's brief (2026-09-17); `teaching_method.md` — the teaching method; `review_2026-09-22.md` — the full review and the refactor map. `parent_brief_template.txt` — the old brief, replaced 2026-09-17 by the human teacher.
- `guard_tag_at_night.sh` — the guard on the long tag, RETIRED 2026-09-19; do not arm it (still here because it is named by its old command line, `archive/guard_args.txt`).

`archive/` holds what the ledger names and no longer runs: `archive/flags/` the kept flag sets (each the served set before or after a change named in ITERATIONS.md), the earlier generations of the morning probe, the reload and the typist relaunch, and (moved 2026-09-23) the night waiter (`night_waiter.sh`, replaced by `night_cycle.sh`), the guard's old command line (`guard_args.txt`) and the pod scripts (`pod_pretrain.sh`, `pod_pretrain_run.sh`; everything runs locally).
